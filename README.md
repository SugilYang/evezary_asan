# 이브자리 코디센 아산풍기점 — 매장 홈페이지

**`index.html` 파일 하나로 동작**하는 매장 소개 홈페이지입니다.
(외부 CSS/JS 파일 없음 · 폰트만 CDN 사용 · 온라인 판매 없음 → 전화·방문 유도 구성)

- 로컬에서 보기: `index.html` 을 브라우저로 열기
- GitHub Pages 주소: `https://sugilyang.github.io/evezary_asan/`
  (저장소 Settings → Pages → Branch: `main`, 폴더 `/ (root)` 선택하면 켜집니다)

## 1. 매장 사진 넣기 (가장 먼저!)

`assets/photos/` 폴더에 아래 파일명으로 **직접 찍으신 매장 사진**을 넣으면
"매장 한 바퀴" 섹션에 자동으로 나타납니다. 사진이 없으면 예쁜 준비중 카드가 대신 보입니다.

| 파일명 | 설명(캡션) |
|---|---|
| `01.jpg` | 매장 전경 |
| `02.jpg` | 이번 시즌 신상 침구 |
| `03.jpg` | 베개 체험 코너 |
| `04.jpg` | 혼수 · 예단 코너 |
| `05.jpg` | 아이 방 침구 |
| `06.jpg` | 상담 공간 |

가로 사진, 1200px 이상 권장. 파일명·캡션은 `index.html`의 `PHOTOS` 상수에서 바꿀 수 있습니다.
사진을 넣는 가장 쉬운 방법: **Claude 채팅에 사진을 첨부하고 "갤러리에 넣어줘"라고 하면**
알아서 이름을 맞춰 커밋해 드립니다. (매장 블로그 https://blog.naver.com/duddmsl86 의 사진은
직접 찍으신 것이니 저장해서 올리시면 됩니다. 단, 이브자리 본사 제품 사진을 쓰실 때는
본사 대리점 정책상 허용 범위를 한 번 확인해 주세요.)

## 2. 내용 수정하기

`index.html` 아래쪽 `<script>` 안, **`★ 여기만 고치시면 됩니다`** 주석 아래 상수만 바꾸면 됩니다.

| 상수 | 바뀌는 곳 |
|---|---|
| `STORE` | **전화·주소·영업시간·주차·SNS 링크** |
| `PHOTOS` | 매장 사진 파일명과 캡션 |
| `STRIP` | 첫 화면 아래 숫자 4개 |
| `WHY` | "매장에서 골라야 하는 이유" 카드 4개 |
| `STEPS` | 수면 상담 5단계 |
| `LINES` | 제품 라인업 카드 6개 |
| `PACKS` | 혼수·이사 상담 카드 3개 |
| `SEASON` | 이번 시즌 추천 3개 (계절마다 교체) |
| `FAQ` | 자주 묻는 질문 |
| `VOICES` | 방문 후기 — 비어 있으면 섹션이 표시되지 않습니다. 실제 후기만 넣어주세요 |
